Avant d'installer

T3 Code n'est pas une IA : c'est une appli qui pilote les agents de code déjà installés sur ton ordinateur (Claude Code, Codex, Cursor, OpenCode, Grok Build, Antigravity, Kiro…). Il te faut au moins un agent installé et connecté (par exemple `claude auth login` ou `codex login`). Trois façons de l'utiliser :

Sur ton PC (Windows, Mac, Linux)

Télécharge l'appli sur t3.codes/download, ou en une ligne : winget install T3Tools.T3Code (Windows), brew install --cask t3-code (Mac), yay -S t3code-bin (Arch), .deb pour Debian/Ubuntu. Pour l'essayer sans rien installer : npx t3@latest (Node.js récent).

Le plus simple

Sur un serveur ou un NAS

Lance t3 up sur la machine qui fait le travail (serveur, VPS, PC fixe) : il tourne en service de fond et tes autres appareils s'y connectent par le réseau local, Tailscale ou T3 Connect.

Pour les habitués

Sur ton téléphone

Applis iOS et Android, ou le site app.t3.codes. Le téléphone est une télécommande : c'est ton ordinateur qui fait le travail, il doit rester allumé et joignable.

PC allumé obligatoire

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit et open source (MIT). On ne peut pas payer T3 Code : il ne revend pas de crédits et utilise tes abonnements existants (Claude, ChatGPT/Codex, Cursor…). Tu continues de payer ton fournisseur comme avant.
  • ↔T3 Connect, gratuit pour l'instant : l'accès à distance intégré est gratuit jusqu'à 3 machines par compte (téléphones et navigateurs non comptés) ; l'équipe prévient que ça pourrait changer. Tailscale ou le réseau local restent possibles.
  • !Ton code part chez l'agent choisi : T3 Code tourne chez toi, mais Claude, Codex ou Cursor envoient toujours ton code à leurs serveurs, comme sans T3 Code.
  • ⚠Encore jeune : version 0.1.11 (20 novembre 2026), projet ouvert en février 2026. Ça bouge vite : mets-le à jour régulièrement.
  • ↔Dans la vidéo : « Autoriser » = les demandes d'autorisation des agents (voir les modes de permission de la doc) ; « un clic ouvre la pull request » = le bouton Commit, push & PR, après connexion à GitHub ; changer de modèle en plein fil est une fonction du README.

Un projet très actif, porté par une équipe connue et une énorme communauté, sans modèle payant ; sa jeunesse (version 0.1) reste le principal point de vigilance.

Maturité 3/5

Ouvert en février 2026 et encore en version 0.1 : rapide à évoluer, avec des bugs possibles.
