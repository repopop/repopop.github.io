Avant d'installer

AdGuard Home est un serveur DNS que tu installes chez toi. Chaque appareil qui l'utilise lui demande l'adresse des sites ; s'il s'agit d'un domaine de pub ou de pistage, il répond « introuvable » et rien ne se charge. Règle-le une fois dans ta box (ou ton routeur) et tous les appareils du Wi-Fi sont filtrés, la télé comprise, sans rien installer dessus. Il faut un appareil allumé en permanence. Trois façons de l'installer :

Raspberry Pi ou mini-PC

Script d'installation officiel pour Linux, macOS et FreeBSD (aussi Windows en téléchargement). Un Raspberry Pi suffit largement. Assistant de configuration dans le navigateur sur le port 3000.

Installation directe

Docker

Image Docker officielle. Prévois des volumes persistants pour la configuration et les données, et vérifie les ports DNS et interface web avant de démarrer.

Ports à régler

Snap ou NAS

Paquet Snap pour Linux. Sur un NAS, passe par Docker (Synology, QNAP…), en réglant les ports pour libérer le 53.

Selon ton NAS

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Le logiciel est gratuit et sous GPL-3.0. Pas d'abonnement requis. Le matériel, l'électricité et le temps de configuration restent à ta charge.
  • ⌂Les journaux et statistiques restent sur ton installation. La politique indique que les journaux DNS restent sur l'appareil. Les requêtes autorisées partent vers ton DNS amont ; si tu actives les contrôles de sécurité web, ils peuvent envoyer un préfixe de quatre caractères du hash du domaine.
  • ↔Le filtrage concerne les domaines DNS. Il ne supprime pas forcément les pubs intégrées au contenu d'une appli ou d'une vidéo ; des domaines partagés entre contenu et publicité compliquent aussi le blocage.
  • !Le port 53 peut déjà être utilisé. Le DNS écoute habituellement sur le port 53. Un autre service peut l'occuper ; il faut aussi les droits nécessaires et, selon le système, configurer le pare-feu.
  • !Tes appareils doivent utiliser ce DNS. Le plus simple : mets l'adresse d'AdGuard Home comme DNS dans les réglages de ta box. Sinon, change le DNS appareil par appareil. Hors de chez toi (4G/5G), le téléphone n'est plus filtré, sauf si tu passes par un VPN ou le DNS chiffré d'AdGuard Home.

5 usages concrets

01

Une maison sans pubs, même la télé

Règle le DNS une fois dans ta box : téléphones, ordis, tablettes et télé connectée sont filtrés, sans appli à installer sur chacun.

Ta box→AdGuard Home→Tous tes appareils
02

Voir ce que ta télé contacte

Le journal des requêtes montre en direct quels sites chaque appareil appelle. Tu découvres vite que ta télé ou ta box TV parle à des serveurs de mesure d'audience.

JournalPar appareil
03

Protéger les enfants

Active le contrôle parental et force la recherche sécurisée (Google, Bing, YouTube…) seulement pour les appareils des enfants grâce aux réglages par appareil.

ParentalRecherche sûre
04

Bloquer hameçonnage et malwares

La protection de navigation bloque les domaines connus pour l'hameçonnage ou les logiciels malveillants, sur tout le réseau.

SécuritéListes
05

Réparer un site cassé en un clic

Un site ne marche plus ? Retrouve le domaine bloqué dans le journal et autorise-le en un clic : la règle s'applique à toute la maison.

AutoriserRègle

Note de confiance

8,4/10

Fiable, à bien régler

Le logiciel est libre et actif. Il conserve le journal sur ton installation, mais les requêtes autorisées doivent toujours atteindre un DNS amont et le filtrage par domaine a des limites.

Activité du projet 4/5

La version stable 0.107.80 a été publiée le 3 novembre 2026 ; le dépôt reste actif et publie aussi une branche bêta distincte.

Communauté 4/5

38 323 étoiles sur GitHub le 10 novembre 2026 ; c'est l'une des deux références du blocage DNS chez soi, avec Pi-hole.

Respect de tes données 4/5

Les journaux restent sur l'appareil selon la politique officielle. Les requêtes autorisées sont transmises au DNS amont choisi ; ce fournisseur voit donc ces requêtes.

Modèle économique 5/5

Logiciel libre sous GPL-3.0, sans abonnement. Il faut néanmoins fournir et alimenter un ordinateur ou un serveur.

Maturité 4/5

Documentation, interface web, paquets, image Docker et versions stables existent ; l'installation DNS demande de configurer ports et appareils.

Comment on note : 5 critères notés sur 5, vérifiés sur le dépôt GitHub, les notes de version et la documentation officielle le 12 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.

Notre verdict

  • ADGUARD HOMEsi tu veux héberger un filtre DNS chez toi et garder la main sur ses listes et ses règles.
  • PI-HOLEsi tu préfères l'alternative communautaire connue, également gratuite et locale.
  • NEXTDNSsi tu veux éviter de maintenir un serveur et acceptes que les requêtes passent par un service cloud.

Le DNS ne bloque pas toutes les publicités. Une appli ou une vidéo peut servir ses pubs depuis les mêmes domaines que son contenu ; sur iPhone, le DNS du Wi-Fi ne s'applique pas au réseau mobile.
