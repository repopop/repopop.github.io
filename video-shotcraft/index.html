Avant d'installer

video-shotcraft est une skill (une compétence) pour Claude Code ou Codex : elle transforme ton agent IA en studio de motion design. Tu demandes « fais-moi une promo de mon produit » : l'agent capture tes vraies pages, choisit des plans dans une bibliothèque de 150 plans (titres, mouvements de caméra, transitions, graphiques…), écrit le storyboard, anime le film avec Remotion, cale les coupes sur le rythme de la musique, ajoute les bruitages, vérifie chaque image et te livre un MP4. Ce n'est pas un générateur de vidéo par IA : chaque image est dessinée par du code à partir de tes captures et de tes textes, donc c'est net, fidèle à ta marque et modifiable. La différence avec HyperFrames (vidéo n°09) : HyperFrames est l'outil de base pour faire des vidéos en code ; video-shotcraft est une méthode clé en main pour un usage précis, le film promo de ton produit.

Par ton agent IA (le plus simple)

Dans Claude Code ou Codex, écris : « Install this skill for me: https://github.com/Vincentwei1021/video-shotcraft ». L'agent l'installe tout seul. Il te faut aussi Node.js et npm, et ffmpeg / ffprobe pour les vérifications et le rendu final.

Recommandé

Avec la commande skills

npx skills add Vincentwei1021/video-shotcraft. Ou à la main : git clone du dépôt, puis un lien symbolique vers ~/.claude/skills/video-shotcraft (Claude Code) ou ~/.codex/skills/video-shotcraft (Codex).

Une commande

Sur Windows ou Linux

Le projet est testé sur Mac. Sous Linux sans écran, il faut trois réglages (--concurrency=1, un chrome-headless-shell, et --browser-executable si le téléchargement est bloqué). Windows n'est pas mentionné : ça peut marcher, mais sans garantie.

Non testé

Ce qu'il faut savoir (lu pour toi dans la doc)

  • ✓La skill est gratuite et open source. Le code et la documentation sont sous licence Apache 2.0. Tu peux t'en servir pour tes propres produits, y compris commerciaux.
  • €Il te faut un agent IA. La skill tourne dans Claude Code ou Codex : c'est ton abonnement (Claude, ChatGPT) ou ta clé API qui paie le travail de l'agent. Un film complet demande beaucoup d'étapes, donc beaucoup d'usage.
  • !Remotion : gratuit… jusqu'à 3 personnes. Le moteur vidéo, Remotion, a sa propre licence : gratuit pour un particulier, une association ou une entreprise de 3 personnes maximum, même pour un usage commercial. Au-delà, une licence entreprise est obligatoire (25 $ par mois et par poste, 100 $ par mois minimum).
  • ▭Une vidéo en 16:9. Le film sort en MP4 1920 × 1080, 30 images/s : parfait pour ton site, YouTube ou une présentation. Pour TikTok ou les Reels, il faut demander à l'agent un format vertical ou recadrer.
  • ♪Les sons ont leurs propres licences. Les bruitages viennent de Freesound (CC0 ou CC BY) et sont téléchargés pour chaque projet ; garde la liste des sources et crédite les auteurs quand la licence CC BY le demande. Les 5 musiques fournies ont aussi leurs crédits (ATTRIBUTION.md).
  • ⚠Attention à ce que tu montres. Tes captures passent par l'agent IA. Avant de publier, retire ou floute les données de clients, les adresses e-mail ou tout ce qui est personnel, et remplace les captures de démonstration du modèle par les tiennes.

Note de confiance

7,6/10

Très suivi et très soigné, mais tout jeune

video-shotcraft est l'œuvre d'un développeur, Vincent Wei, et dépasse 13 000 étoiles sur GitHub (environ 13 900 en novembre 2026) et 1 300 forks. Il apparaît sur Trendshift, le classement des dépôts qui montent, et compte AWS parmi ses sponsors. Ses 150 plans ont été mis au point en étudiant les films promo officiels de ClickUp, Perplexity, Slack, Notion, Figma, Raycast et d'autres : les techniques (rythme, courbes, chorégraphie) sont refaites de zéro, sans aucune image ni logo de ces marques, qui ne sont pas partenaires du projet. L'auteur précise que la bibliothèque a elle-même été construite et vérifiée avec Claude Code.

Activité du projet 5/5

Nouveautés chaque mois depuis août 2026 (export JianYing, éditeur Motion Workbench en septembre, refonte de la bibliothèque en octobre).

Communauté 4/5

Environ 13 900 étoiles et 1 300 forks, une page Showcase pour les films de la communauté ; mais un seul auteur principal.

Respect de tes données 4/5

Le rendu se fait sur ta machine ; en revanche, tes captures et ton projet passent par l'agent IA (Claude ou Codex). La publication sur les réseaux est optionnelle.

Modèle économique 3/5

Projet personnel soutenu par des sponsors et des dons ; le moteur Remotion devient payant pour les entreprises de 4 personnes ou plus.

Maturité 3/5

Projet récent (premières nouveautés annoncées en août 2026), testé sur Mac seulement, pas encore de versions numérotées.

Comment on note : 5 critères notés sur 5, vérifiés sur GitHub, le README et SKILL.md du dépôt, la licence de Remotion et les pages de prix d'Adobe et de Screen Studio le 16 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.
