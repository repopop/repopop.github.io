C'est quoi ?

Une API (interface de programmation) est la porte d'entrée qu'un logiciel ouvre aux autres logiciels. Comme le serveur d'un restaurant : tu ne vas pas en cuisine, tu choisis dans le menu, le serveur transmet ta commande et te rapporte le plat. Ton appli n'a pas besoin de savoir comment le service travaille : elle demande, il répond.

Le menu : la documentation

Chaque API publie la liste de ce qu'on peut lui demander (la documentation) : quelles infos, sous quelle forme, avec quelles options.

Public

La commande : une adresse

Une demande à une API est le plus souvent une simple adresse web avec des options (ville, date…). Ton appli l'envoie, sans écran ni clic.

Automatique

Le plat : la réponse

Le service renvoie une réponse structurée (souvent au format JSON), que l'appli met en forme : « 2,4 °C à Paris » devient une jolie icône.

En une fraction de seconde

La clé : ton badge

Beaucoup d'API demandent une clé API pour savoir qui commande (et qui paie). Elle se garde comme un mot de passe. Certaines, comme Open-Meteo pour un usage non commercial, s'en passent.

Selon l'API

Ce qu'il faut savoir (lu pour toi dans la doc)

  • ⚠Une clé API, c'est comme ta carte bleue. Ne la colle jamais dans un message, une capture ou un dépôt public : quelqu'un pourrait s'en servir à tes frais. En cas de fuite, supprime-la et crée-en une nouvelle.
  • €Gratuit pour essayer, payant à grande échelle. Beaucoup d'API ont une offre gratuite limitée (nombre de demandes par jour), puis se paient à l'usage. Exemple : Open-Meteo est gratuit pour un usage non commercial, avec moins de 10 000 appels par jour.
  • ↔Abonnement ≠ API chez les IA. Chez Anthropic comme chez OpenAI, l'API des IA (Claude, ChatGPT) se paie à part de l'abonnement au chat, sur leur plateforme pour développeurs.
  • !Uber et Google Maps. Dans son dossier d'entrée en Bourse (2019), Uber indique avoir payé environ 58 millions de dollars à Google pour Google Maps entre 2016 et 2018, un service qu'il juge « critique » pour son appli.
  • ⌂L'État aussi publie des API. Le catalogue de data.gouv.fr (anciennement api.gouv.fr) référence les API publiques de l'administration française : adresses, entreprises, service-public.fr…

Comment ça marche

Exemple réel avec Open-Meteo, une API météo gratuite pour un usage non commercial, sans clé ni inscription. Le site est en anglais : voici où regarder.

1

Le menu : la documentation

open-meteo.com › API Docs › Hourly Weather Variables

La page API Docs liste tout ce qu'on peut demander : température, pluie, vent… Coche Temperature (2 m) : la page fabrique l'adresse de ta commande plus bas.

2

Le plat : la réponse

Adresse de la demande › Réponse JSON

Ouvre l'adresse dans ton navigateur : l'API répond aussitôt en JSON. Ici, temperature_2m vaut 2.4 : 2,4 °C à Paris, à 0 h 30.

3

5 usages concrets

01

La météo de ton appli

Ton téléphone ne mesure rien : l'appli demande les prévisions à un service météo par son API.

Ton appli→API météo→2,4 °C
02

Se connecter avec Google

Le site ne voit jamais ton mot de passe : il demande à Google, par son API, de confirmer que c'est bien toi.

ConnexionSans mot de passe
03

Payer en ligne

La boutique transmet le paiement à un service spécialisé (banque, Stripe, PayPal…) par son API, et reçoit « payé » ou « refusé ».

Panier→API de paiement→Payé ✓
04

Une carte dans une appli

Uber n'a pas codé ses cartes : il utilise l'API de Google Maps pour l'itinéraire et l'heure d'arrivée.

Google MapsItinéraire
05

Une IA qui agit

Claude, ChatGPT et les autres IA peuvent se brancher sur des API (directement ou par des connecteurs) pour chercher une info à jour ou agir : créer un rendez-vous, envoyer un mail…

Ta demande→IA→API→C'est fait
