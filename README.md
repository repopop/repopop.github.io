# RepoPop · les kits

Site des kits RepoPop : chaque dépôt GitHub présenté dans nos vidéos (Instagram, TikTok, YouTube Shorts : @repo_pop), expliqué simplement en français.

- `index.html` : catalogue de tous les kits
- `<nom-du-depot>/index.html` : un kit par vidéo (ex. `stirling-pdf/`)
- `assets/` : styles communs (`kit.css`), polices, images de Setei et aperçus de lien (`og/`)

En ligne : https://repopop.github.io
