Avant d'installer

REA, pour Reverse Engineer Anything, est un serveur MCP et un outil en ligne de commande. Il branche ton agent IA (Claude Code, Codex, Cursor, Gemini CLI…) sur de vrais outils de rétro-ingénierie : programmes natifs (pseudo-code, assembleur, chaînes, symboles), applis JavaScript et Electron, applis Android, .NET, Go, Rust, WASM, sites web, captures réseau et comportement des processus. Tu demandes en français comment marche une fonction ; l'agent appelle REA, qui renvoie ses trouvailles avec les preuves et les limites. Le README annonce plus de vingt types de cibles.

Sur ton PC, avec ton agent

npx rea-agents setup, puis relance ton agent : REA s'inscrit dans Claude Code, Codex, Cursor, Gemini CLI… Il montre les changements, demande ton accord et sauvegarde ta configuration avant. Il faut Node.js 22 ou plus récent. macOS et Linux sont les plus complets ; sous Windows, une partie des fonctions seulement (Ghidra y est expérimental).

Recommandé

En ligne de commande seule

npm install --global rea-agents, puis rea --help : les mêmes analyses, sans agent, pour les scripts. Mise à jour avec rea update.

Pour scripter

Linux et Docker pour l'avancé

Certaines fonctions sont réservées à Linux (captures TShark, plantages avec pwntools, signaux sigrok) ; la création d'environnements d'entraînement à partir d'applis de bureau demande Linux (amd64 ou arm64) et Docker.

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit, licence MIT. Le code de REA est sous licence MIT. Les composants tiers gardent leur propre licence (liste dans THIRD_PARTY_NOTICES.md).
  • ⚠Seulement ce que tu as le droit d'étudier. REA est prévu pour la recherche légale, la sécurité, l'interopérabilité, la préservation et les logiciels que tu possèdes ou que tu es autorisé à analyser. Il refuse d'aider à contourner des DRM, tricher, casser une licence ou copier du code propriétaire. La loi et la licence du logiciel étudié peuvent aussi l'interdire.
  • !Il faut un décompileur pour aller au fond. Pour les programmes natifs, REA pilote Ghidra (gratuit), IDA, Hopper ou Kuna déjà installés : il n'installe ni Ghidra ni IDA, et ne fournit aucune licence. Les applis JavaScript, Electron et .NET s'analysent sans.
  • ↔Ton IA voit les résultats. L'analyse tourne sur ta machine, mais le fournisseur du modèle de ton agent reçoit les résultats des outils, selon sa propre politique de données.
  • ⚠Méfie-toi des copies. Télécharge REA seulement depuis le dépôt morluto/rea, le site rea.tools ou le paquet npm rea-agents : le README prévient que des copies circulent.
  • ⏱Projet jeune qui bouge vite. Créé en avril 2026, mises à jour très fréquentes. Certaines nouveautés du dépôt ne sont pas encore dans la dernière version npm ; les gros programmes peuvent demander un délai de démarrage plus long.

Note de confiance

8,4/10

Énorme succès, gratuit et puissant, mais encore jeune

Projet sous MIT, extrêmement suivi et mis à jour en continu. À surveiller : sa jeunesse, les fonctions réservées à Linux, et le fait que ton fournisseur d'IA voit les résultats des analyses.

Activité du projet 5/5

Plus de 7 300 commits et des versions très fréquentes ; le README demande de mettre à jour souvent.

Communauté 5/5

GitHub affichait environ 455 300 étoiles et 111 800 forks lors de la vérification ; la vidéo arrondit à plus de 450 000.

Respect de tes données 4/5

L'analyse tourne en local, mais les résultats passent par le modèle de ton agent (Claude, OpenAI…).

Modèle économique 4/5

Gratuit sous MIT, sans compte ; pour aller au fond des programmes natifs, IDA ou Hopper restent payants (Ghidra est gratuit).

Maturité 3/5

Créé en avril 2026 : fonctions inégales selon le système, Ghidra sous Windows expérimental, npm parfois en retard sur le dépôt.

Comment on note : 5 critères notés sur 5, vérifiés sur GitHub, le README officiel et des articles publiés le 13 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.
