Avant d'installer

Leonida est un jeu en 3D qui tourne entièrement dans ton navigateur : une ville de 2 km sur 2 inspirée de Vice City, six quartiers, des autoroutes, de l'eau et un cycle jour-nuit. Tout est généré par le code (bâtiments, voitures, passants, sons) : aucun fichier de jeu à télécharger. Deux façons d'y jouer :

En ligne, sur la page du jeu

Ouvre bridge-mind.github.io/leonida dans Chrome, Edge ou Firefox (WebGL2 requis), clique sur « New Game », puis sur l'image pour capturer la souris. Échap met en pause. Il faut un clavier et une souris.

Le plus simple

Sur ton PC, depuis le code

Pour lire ou modifier le jeu : clone le dépôt, puis npm install et npm run dev (Node.js), et ouvre http://localhost:5173. Le code est en TypeScript, avec Three.js (3D) et Rapier (physique).

Pour les curieux

Téléphone et tablette

Pas de version mobile : le README indique qu'aucun contrôle tactile n'est prévu.

Non pris en charge

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit et open source (MIT). Ni compte, ni pub, ni achat dans le jeu. Le code est libre : tu peux le lire, le modifier et t'en servir pour tes propres projets.
  • !Projet de fan, pas un vrai GTA : Leonida n'est ni affilié ni approuvé par Rockstar Games ou Take-Two. Il n'utilise aucun élément de Rockstar (graphismes, logos, polices, musique) ; les noms de lieux et de personnages sont des références de fan. Les graphismes sont simples (« low-poly »).
  • ⚠Très peu testé : le README prévient que le jeu a été très peu essayé en conditions réelles. Exemple de bug connu : le joueur et les objets à ramasser sont invisibles à l'intérieur des bâtiments.
  • ↔Dans la vidéo : « tu lances la partie » = clic sur New Game. La recherche par la police compte 6 niveaux d'étoiles ; le casino propose blackjack, roulette, machines à sous et roue de la fortune ; 8 missions et 6 armes, d'après le README.
  • ⚠Pas de mise à jour depuis la publication : le code a été publié d'un bloc le 2 septembre 2026 et n'a pas bougé depuis. À prendre comme une démo technique, pas comme un jeu suivi.

Note de confiance

4,4/10

Bluffant, mais expérimental

Une démo technique impressionnante et sans risque pour tes données, mais publiée d'un bloc, très peu testée et sans suivi depuis.

Activité du projet 1/5

Une seule publication du code, le 2 septembre 2026, sans modification depuis.

Communauté 2/5

Environ 200 à 250 étoiles et une trentaine de copies (forks) : un petit public, pas de contributeurs extérieurs visibles.

Respect de tes données 4/5

Pas de compte ni de pub : le jeu tourne dans ton navigateur. La page est hébergée par GitHub Pages, qui voit ta connexion comme pour tout site.

Modèle économique 3/5

Gratuit sous licence MIT, non commercial. Il s'appuie sur l'univers d'un jeu de Rockstar : un projet de fan qui peut disparaître à la demande de l'éditeur.

Maturité 1/5

Très peu testé d'après le README, bugs connus, pas de version mobile ni de version publiée.

Comment on note : 5 critères notés sur 5, vérifiés sur GitHub, l'API GitHub, le README et la page du jeu le 23 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.
