Avant d'installer

Claude sait déjà faire beaucoup de choses : une présentation, un tableau, un PDF. Mais il ne connaît pas ta façon de faire : ton modèle, tes couleurs, ton plan, tes étapes. Une skill, c'est un dossier avec un fichier SKILL.md (des instructions écrites une fois), et parfois des scripts et des modèles. Au démarrage, Claude ne lit que le nom et la description de chaque skill (environ 100 tokens chacune) ; il ouvre la fiche complète seulement quand ta demande s'y prête, puis lance ses scripts si besoin. Résultat : tu n'as plus à recoller tes consignes, et le résultat est le même à chaque fois. Le dépôt anthropics/skills contient 17 skills officielles (dont celles qui fabriquent les fichiers Word, Excel, PowerPoint et PDF de Claude), un modèle de départ et la spécification du format.

Dans l'appli Claude

Web, ordinateur ou téléphone : active « Exécution de code et création de fichiers » dans les paramètres, puis Personnaliser > Skills pour activer les skills d'exemple ou importer les tiennes (dossier en .zip).

Le plus simple

Dans Claude Code

Deux commandes : /plugin marketplace add anthropics/skills puis /plugin install document-skills@anthropic-agent-skills (ou example-skills@anthropic-agent-skills). Tes propres skills vont dans ~/.claude/skills/.

Pour les développeurs : les skills d'Anthropic sont prêtes à l'emploi et tu peux envoyer les tiennes avec l'API Skills (outil d'exécution de code requis).

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit. Le dépôt est gratuit et les skills s'utilisent aussi avec l'offre gratuite de Claude (exécution de code activée). Claude Code demande une offre payante (Pro dès 20 $ par mois).
  • !Pas tout en open source. Les skills d'exemple sont sous licence Apache 2.0. Les skills Word, Excel, PowerPoint et PDF sont seulement « source-available » : tu peux les lire et t'en inspirer, pas les réutiliser librement.
  • ⚠Une skill peut lancer des scripts. Lis une skill avant de l'activer, surtout si elle vient d'un inconnu, et méfie-toi de celles qui demandent de se connecter à des sites externes (conseil de l'aide officielle de Claude).
  • !Des exemples, pas des produits finis. Le README précise que ces skills servent de démonstration et peuvent se comporter différemment dans Claude : teste-les avant de t'en servir pour un travail important.
  • ↔Un standard ouvert. Anthropic a publié le format le 18 décembre 2025 sur agentskills.io. OpenAI Codex, GitHub Copilot, VS Code, Gemini CLI, Cursor et une quarantaine d'outils le lisent : une même skill marche presque partout.
  • ✓Presque gratuite tant qu'elle dort. Claude ne lit que le nom et la description d'une skill (environ 100 tokens). La fiche complète et ses fichiers ne sont chargés que si ta demande en a besoin : tu peux en installer beaucoup.

Note de confiance

8,0/10

Officiel, très suivi, devenu un standard

Le dépôt est publié par Anthropic, l'entreprise qui fait Claude, et sert de référence au format Agent Skills, aujourd'hui repris par OpenAI, Microsoft, Google et Cursor. Ses skills sont présentées comme des exemples : à tester avant un usage important.

Activité du projet 3/5

Une soixantaine de commits sur la branche principale ; beaucoup de demandes en attente (plus de 400 tickets et un millier de propositions de modification ouverts).

Communauté 5/5

Environ 187 500 étoiles et 22 000 forks sur GitHub en novembre 2026 ; le format est adopté par une quarantaine d'outils.

Respect de tes données 4/5

Une skill n'envoie rien à elle seule, mais elle s'exécute avec Claude (tes fichiers passent par Anthropic) et une skill d'un inconnu peut lancer des scripts.

Modèle économique 4/5

Gratuit ; exemples sous Apache 2.0, mais les skills de documents ne sont pas open source et Claude Code demande une offre payante.

Maturité 4/5

Format lancé en octobre 2025, standard ouvert depuis décembre 2025 et utilisé tous les jours par Claude pour ses fichiers ; le README parle encore d'exemples de démonstration.

Comment on note : 5 critères notés sur 5, vérifiés sur GitHub, le README officiel, l'aide officielle de Claude et la presse spécialisée le 15 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.
