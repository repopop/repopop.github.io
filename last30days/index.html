Avant d'installer

last30days est un skill : un module que tu ajoutes à ton assistant IA de code. Tu lui donnes un sujet, il cherche ce qui s'en est dit ces 30 derniers jours sur Reddit, Hacker News, X, YouTube et d'autres sources, classe les résultats selon l'engagement réel (votes, likes, vues) et te rend une synthèse avec ses sources. Trois façons de l'installer :

Dans Claude Code

La méthode conseillée par l'auteur : /plugin marketplace add mvanhorn/last30days-skill, puis /plugin install last30days. Il faut Python 3.12 ou plus récent sur ton PC.

Tourne sur ton PC

Cursor, Gemini CLI, Codex

Une seule commande : npx skills add mvanhorn/last30days-skill -g -a cursor (remplace cursor par gemini-cli ou codex). Fonctionne aussi avec une cinquantaine d'autres assistants compatibles.

Tourne sur ton PC

Claude.ai ou Claude Desktop

Tu télécharges le fichier .skill (ou le paquet .mcpb) sur la page des versions du dépôt et tu le glisses dans Claude. Le paquet pour Claude Desktop n'est pas encore pris en charge sous Windows.

Pas encore sous Windows (Desktop)

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit et open source (licence MIT). Reddit, Hacker News, GitHub et Polymarket marchent sans aucune clé ni compte.
  • 🔑X, YouTube, TikTok, Instagram : ces sources demandent une clé ou un outil en plus (yt-dlp pour YouTube, une clé ScrapeCreators pour les réseaux sociaux : 10 000 appels gratuits, puis payant à l'usage).
  • ⌂Tout tourne chez toi : les données ne partent que vers les sites interrogés. Pas de suivi ni de statistiques d'usage selon l'auteur.
  • ↔Clé OpenAI, xAI ou Gemini facultative : si tu en mets une pour mieux trier les résultats, ton sujet et des extraits lui sont envoyés. Sans clé, le tri se fait en local.
  • !Une seule méthode d'installation par machine : si tu installes à la fois le plugin et la version npx, la commande /last30days apparaît en double dans Claude Code.
