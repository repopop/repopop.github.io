Avant d'installer

HyperFrames est un outil open source publié par HeyGen. Une vidéo y est une page web : HTML, CSS et animations (GSAP, Lottie, Three.js…). Un agent IA comme Claude Code, Cursor ou Codex écrit cette page, et HyperFrames la rend image par image dans un Chrome sans fenêtre, puis l'encode en MP4 avec FFmpeg. Les vidéos RepoPop sont elles-mêmes rendues avec HyperFrames.

Sur ton PC ou ton Mac

Le plus simple : Node.js 22 ou plus et FFmpeg, puis npx hyperframes init. L'aperçu s'ouvre dans le navigateur et se recharge à chaque modification.

Recommandé

Dans Docker

Pratique pour un rendu identique d'une machine à l'autre ou sur un serveur. Demande un peu plus de mise en place.

Pour automatiser

Rendu distribué sur AWS Lambda

Pour rendre beaucoup de vidéos en parallèle, dans ton propre compte AWS. Plus lourd à installer et facturé par AWS.

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit, même pour un usage pro. Licence Apache 2.0 : pas de frais par rendu ni de licence par siège, quelle que soit la taille de ton entreprise.
  • ⌂Le rendu se fait chez toi. Aucun compte ni clé d'API n'est nécessaire pour rendre en local. La commande de partage des rendus, elle, demande une connexion à un compte.
  • !Il faut un agent IA, ou savoir coder. Ce n'est pas un logiciel de montage à la souris : tu décris la vidéo à ton IA (ou tu écris le HTML). Le Studio visuel existe mais évolue encore.
  • ↔Fait pour le motion design, pas pour monter tes rushs. Idéal pour titres, sous-titres animés, graphiques, présentations. Pour couper des heures de vidéo filmée, un logiciel de montage reste plus adapté.
  • ⏱Le rendu prend un peu de temps. Chaque image est capturée une par une : compte quelques minutes pour une vidéo de 30 secondes en 1080p sur un PC récent.
  • ⚠Projet jeune. Publié en avril 2026, il évolue très vite : relis le changelog avant de mettre à jour un projet qui marche.
