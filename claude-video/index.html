Avant d'installer

Claude Video n'est pas une IA : c'est un skill (une compétence) qui donne des yeux à ton agent. Il transforme une vidéo (lien YouTube ou autre, ou fichier sur ton PC) en images clés horodatées + transcription minutée, que l'agent lit ensuite. Il te faut un agent de code déjà installé (Claude Code, Codex, Cursor…). Où l'utiliser :

Dans Claude Code

Dans une session : /plugin marketplace add bradautomates/claude-video puis /plugin install watch@claude-video. Dans l'appli Claude (onglet Code) : Personnaliser → Plugins → Ajouter un marketplace, colle l'adresse du dépôt, puis installe Watch.

Le plus simple

Codex, Cursor et 50+ agents

npx skills add bradautomates/claude-video -g --skill watch (installe pour tous tes projets). Pour Codex : codex plugin marketplace add bradautomates/claude-video puis codex plugin add watch@claude-video.

Une ligne

Claude dans le navigateur

Le README actuel indique que Claude Chat et Cowork ne sont pas pris en charge, et que Claude Code sur le web a ses propres limites. Utilise-le dans un agent installé sur ton ordinateur.

Pas pris en charge

Ce qu'il faut savoir (lu pour toi dans la doc)

  • €Gratuit et open source (MIT). Le skill ne coûte rien. Tu paies seulement ton agent comme d'habitude (abonnement Claude, ChatGPT/Codex…). La clé Gemini, facultative, est gratuite chez Google AI Studio.
  • ↔Deux moteurs, à choisir : local = ffmpeg et yt-dlp découpent la vidéo sur ton PC, rien ne part chez Google. Gemini = la vidéo est envoyée au modèle vidéo de Google (supprimée après la réponse). En mode auto, Gemini est utilisé dès qu'une clé est trouvée : force --engine local si tu veux rester chez toi. Dans tous les cas, les images et le texte partent à ton agent (Claude, Codex…).
  • !Pré-requis : Python 3.10+, FFmpeg/ffprobe, la dernière version de yt-dlp, et un moteur JavaScript (Deno conseillé) pour YouTube. L'installeur signale ce qui manque (et l'installe via Homebrew sur Mac).
  • ⚠Vidéo sans sous-titres : les sous-titres d'origine sont lus en premier. Sinon : WhisperX en local (environ 3 Go de disque, 8 Go de RAM, vérifié seulement sur Mac Apple Silicon), ou Groq / OpenAI avec ta propre clé API.
  • ↔Dans la vidéo : « la minute exacte » = les images et la transcription sont horodatées ; « le texte affiché à l'écran » = Claude lit les images (ajoute --resolution 1024 pour du petit texte) ; « deux commandes » = l'installation dans Claude Code. La réponse dépend de la qualité de la vidéo et de l'agent.

5 usages concrets

01

Trouver le bon passage d'un tuto

Tu colles le lien d'une vidéo d'une heure et tu demandes à quel moment il fait le réglage qui t'intéresse.

Lien YouTube→Ta question→Minute exacte
02

Résumer une conférence

/watch avec le niveau transcript ou efficient : un résumé minuté sans regarder la vidéo en entier.

Vidéo 1 h→/watch→Résumé minuté
03

Analyser un bug filmé

Tu enregistres ton écran pendant que l'appli plante : l'agent repère l'image où ça casse et lit le message d'erreur.

Enregistrement→Images clés→Le moment du bug
04

Lire le texte à l'écran

Code, réglages, diapos : ce qui est montré mais jamais dit. Monte la résolution pour le petit texte.

--resolution 1024--timestamps 1:05,2:30
05

Zoomer sur un passage

Analyse seulement un intervalle, avec plus d'images, pour une démonstration rapide.

--start 2:15--end 2:45--detail balanced

Note de confiance

7,6/10

Très populaire, encore jeune

Un outil simple et très adopté, gratuit, qui peut tout faire sur ton PC ; il reste en version 0.3 et n'a pas été mis à jour depuis septembre.

Activité du projet 3/5

Version 0.3.2 publiée le 25 septembre 2026, dernière modification du code à cette date ; environ 200 tickets ouverts.

Communauté 5/5

Environ 21 600 étoiles et 2 300 copies (forks) en sept mois ; le projet a inspiré d'autres versions (khou/watch-video).

Respect de tes données 4/5

Moteur local sans envoi à Google ; le moteur Gemini envoie la vidéo à Google (supprimée après) ; images et texte vont à ton agent.

Modèle économique 4/5

Gratuit sous licence MIT, rien à vendre dans le dépôt ; publié par un créateur qui vend de l'automatisation IA.

Maturité 3/5

Ouvert en avril 2026, encore en 0.3 ; tests automatiques sous Linux, Mac et Windows, mais WhisperX vérifié seulement sur Mac Apple Silicon.

Comment on note : 5 critères notés sur 5, vérifiés sur GitHub, l'API GitHub et le README officiel le 24 novembre 2026. La note sur 10 est la moyenne ramenée sur 10.
